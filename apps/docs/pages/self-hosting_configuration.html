The service is configured with environment variables.

Variables

VariableMeaning
DATABASE_URLThe Postgres connection string. Required.
TC_PUBLIC_URLThe address people and local tools use. Required.
TC_SECRET_KEYA long random string for signing sessions and tokens. Required.
TC_SMTP_URLThe mail server for magic links and reminders. Required for magic links.
TC_GOOGLE_CLIENT_ID, …_SECRETGoogle sign-in. The same pair exists for GitHub and Microsoft.
TC_LICENSE_KEYThe Enterprise plan license key. Only the enterprise image reads it. See License key.
TC_PRICES_REFRESHSet to off to stop the daily price table refresh, for instances without internet access.
