Codex CLI pushes usage over OpenTelemetry to your organization's ingest URL. The CLI also reads Codex session files, which adds the branch and lets agent managers review before they submit.

Set up

Point the agent's OpenTelemetry exporter at https://app.tokencontroller.com/api/v1/ingest/otlp and send your organization token as Authorization: Bearer tc_org_…. Find the token under Settings in the web app.

What it sends

Numbers and identifiers only: tokens, cost, model, person, repository, session and message IDs. See Telemetry push for what telemetry can and cannot see.
