A bill is a provider's figure for one period's token usage: gross, discount, credit and net. Token entries must add up to it. Seats, subscriptions and other flat fees are not usage: they stay off the bill and off the cost sheet, and finance handles them as before.

A provider can restate a bill. Each bill keeps its revisions.

Reconciliation

For each period: postings plus unattributed plus residual equal the bill. Residual is the part of the usage no token entry explains, such as chat usage or a restated bill. It is always shown.

List value and billed value

Every token entry has a list value: the agent's reported cost where it has one (Claude Code does), otherwise its token counts times the price table for the model. A billed value exists where a bill or billed telemetry says what was actually charged. Every figure is labelled billed, list-price estimate, or unknown model.
