Cursor Enterprise pushes usage over OpenTelemetry to your organization's ingest URL, with its own names for the same fields. Token Controller maps them. Session files are not read.

Set up

Point the agent's OpenTelemetry exporter at https://ingest.tokencontroller.com and send your organization token as Authorization: Bearer tc_org_…. Find the token under Settings in the web app.

What it sends

Numbers and identifiers only: tokens, cost, model, person, repository, session and message IDs. See Telemetry push for what telemetry can and cannot see.
