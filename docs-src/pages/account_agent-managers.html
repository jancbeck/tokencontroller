Every token entry has exactly one agent manager, the person who answers for its cost. It is the cost center the posting lands on.

Who it is

  • For your own sessions: you.
  • For a CI agent or another automation: the person who set it up, by creating the service token it reports with.

A token entry without one

If an automation's service token belongs to nobody, for example because its creator left, its token entries show as an error to people managers until someone takes the token over.

Handing an automation over

Move the service token to another person in the web app. Only future token entries follow; past postings keep the agent manager they had.
