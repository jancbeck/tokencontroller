A project is a body of work made of tickets. A client is a label on a project.

What a project has

  • a ticket key pattern, such as ^KD-\d+
  • its repositories
  • a client label and any tags you like
  • optionally a token budget and a cadence

Clients

A client is a label, not a separate level. Give several projects the same client label and reports can total them. An agency that wants to see cost per client labels each client's projects.

Cost that belongs to no ticket

Project work that belongs to no single ticket, such as research or setup, is project overhead. Work that belongs to no project at all is organization overhead.
