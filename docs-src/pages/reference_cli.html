Every tc command.

Commands

CommandWhat it does
tc connect URLConnect to an organization with an invite link, or to a self-hosted instance.
tc statusOrganization, person, agents found, rules, and today's cost and attribution.
tc reviewList draft token entries and where they were placed.
tc place N TARGETPlace token entry N on a ticket or project. --personal marks it as personal.
tc submitSubmit your token sheet.
tc report --by ticket|project|dayCost in a table.
tc export --csvAll token entries as CSV.
tc rulesList, add and order personal rules.
tc config KEY VALUESettings, such as classifier.

Every command takes --help.
