# Token Controller

Cost accounting and management control for AI agents.

This repository is the public specification of the product:

- `docs/`: the docs, published at [tokencontroller.com/docs](https://tokencontroller.com/docs). They say exactly how Token Controller works.
- `GLOSSARY.md`: what every term means. The docs use these words, and only these.

`docs-src/` holds the page sources and the script that builds `docs/` from them.
