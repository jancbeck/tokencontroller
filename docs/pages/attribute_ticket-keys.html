A ticket key pattern tells Token Controller how a project's tickets are named, so it can find them in branches, pull requests and prompts.

Set the pattern

Each project has one pattern, a regular expression. For Jira-style keys:

^(KD|OPS)-\d+

For GitHub Issues, where tickets are numbers, use the repository with the number, such as storefront#\d+.

Where keys are found

In the branch name, in the pull request title, and in your prompts. Only the keys leave the machine, never the prompt.

Keys for tickets Token Controller does not know

If a key matches the pattern but the ticket has not synced yet, the token entry is placed on it anyway, and the ticket fills in at the next sync.
