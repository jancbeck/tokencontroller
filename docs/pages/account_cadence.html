A token sheet is how usage that exists only on a person's machine reaches the organization. A cadence says how often token sheets are due.

Token sheets

A token sheet holds one agent manager's token entries for one cadence period that were not reported automatically. Cloud, CI and telemetry token entries never go on a token sheet. The agent manager reviews the drafts and submits the sheet whenever they like.

Cadence

A people manager can set a cadence for a project or the whole organization: weekly, every two weeks, monthly, or custom. The point is that people report while they still remember what the work was for, not three weeks later.

Late

A token sheet whose cadence period is over and that has not been submitted is late. The only consequence is a reminder to its agent manager, in the Claude Code mod and in the web app. Nobody is blocked and nothing is capped.
